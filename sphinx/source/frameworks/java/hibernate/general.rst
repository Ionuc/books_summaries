Hibernate
=========
- Hibernate is a framework for persisting/ saving JAva objects in a database
- the project can be found on www.hibernate.org/orm

Benefits
--------
- handle all of the low-level SQL
- minimuzes the amount of JDBC code you have to develop
- provides the Object-to-Relation Mappings (ORM)

How is work
-----------
- Hibernate / JPA uses JDBC for all database communications
- is just another layer of abstraction on top of JDBC
- you define the mapping between entity fields to the column tables
