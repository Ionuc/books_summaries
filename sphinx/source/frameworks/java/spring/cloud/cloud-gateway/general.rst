General
=======
- Spring Cloud Gateway is used to create a gateway component
- this component can:
    - create routes to internal microservices:
        - all clients needs to know only one URL
    - perform caching for result for the same requests
    - perform authentication and authorisation:
        - internal microservices can communicate directly without any other authentication
