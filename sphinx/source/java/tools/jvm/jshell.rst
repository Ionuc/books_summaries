JShell
======
- is introduced in JAva 9
- is a REPL (Read-Eval-Prin Loop) tool
- introduced to provide a lightway interactive enviroment for experimenting with Java code snippets, expressions and statements
- provides an interactive command line interface where you can type Java code directly and see the results
- is designed to make it easy to experiment, test small code snippets and learn Java without the need for a full development enviroment
