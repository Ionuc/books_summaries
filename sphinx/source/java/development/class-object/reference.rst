Reference Types
===============
- in Java, there are 4 types of reference:
    - Strong reference
    - Soft reference
    - Weak reference:
        - the object will be cleared if it can only be reached by the WeakReference chain
    - Phantom reference
- the specific of eahc link type are related to the way of how Garbage Collection works
