Object Oriented Programming
===========================

- inheritance
- polymorphism
- encapsulation
- abstraction

Inheritance
-----------
- refers that a child class can access to the fields and behavior of the parent class
- you can increase access level during overridding methods

Polymorphism
------------
- means many forms behavior
- it works when extending any class or implement interfaces
- dynamic binding:
    - method that should be invoked is identified during the runtime


Encapsulation
-------------
- group data and behavior together as a single unit
